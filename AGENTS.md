## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for `QOKIK/2026-hduHelp-task`; use `gh` with `--repo QOKIK/2026-hduHelp-task`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default labels `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout: root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.

## Branch workflow

Use `dev` as the primary working branch and push changes to `origin/dev`. Keep `main` for stable versions.
