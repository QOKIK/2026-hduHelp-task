# 首页动效需求

## 目标与范围

为“拾光”首页增加克制、柔和的编辑式动效，突出首页内容层次并为操作提供轻量反馈，不改变页面的信息结构和主要操作路径。

本阶段覆盖首页浏览页的首屏、信息板、线索卡片和相关按钮。按页面逐步扩展时，再单独梳理详情、个人内容、管理后台和弹窗动效。

## 动效要求

### 首屏入场

- 每次完整加载页面时播放一次；在单页应用内离开再回到首页时不重播。
- 左侧文案按眉题、标题、说明、发布按钮的顺序依次出现，随后出现右侧插画。
- 插画按光盘与轨道、纸卡、浮签与印章的顺序出现。
- 整体入场约为 0.8–1 秒，元素之间轻微错开。
- 不添加持续循环的漂浮、旋转或呼吸动效。

### 信息板与卡片

- 信息板标题和筛选栏先成组显现，卡片随后轻微错开出现。
- 每张卡片首次进入视口时显现一次；滚出后再滚回来不重播。
- 卡片的错开总延迟控制在约 0.4 秒内。
- 初次加载数据期间显示静态卡片占位；真实数据到达后替换占位并显现真实卡片，不使用循环闪烁效果。
- 搜索或筛选等待期间保留当前卡片，并给出轻量的“正在更新”提示。结果返回后，只显现新出现的卡片；手动刷新不让全部卡片重播。
- 成功返回空结果时，空状态轻微淡入。请求失败时显示错误提示，不把错误呈现为“没有结果”。

### 操作反馈

- 卡片保留现有的轻微上移和柔和阴影，不增加倾斜效果。
- 桌面端按钮 hover 时轻微变色或移动箭头；触屏/点击时有短暂轻压反馈。
- 保留当前键盘焦点可见样式；不能只用 hover 动效表达状态。

### 移动设备与减少动态效果

- 窄屏保留必要动效，但缩短时长并减小位移。
- 当系统或浏览器启用“减少动态效果”时，跳过首屏入场和滚动位移动画，让内容直接可见。
- 减少动态效果模式下仍可保留必要的颜色反馈和即时状态变化；键盘焦点样式不变。

## 验收边界

1. 首次打开首页时，文案与插画按指定顺序入场；单页内切回首页不重播首屏动画。
2. 信息板进入视口后，标题/筛选栏先出现，卡片随后轻微错开；每张卡片只在首次进入视口时播放一次。
3. 首次数据加载期间显示占位；数据返回后显示实际内容。加载状态不会被误显示为空结果。
4. 搜索/筛选期间旧结果仍可见并显示更新提示；新结果只让新增卡片显现，手动刷新不会重播所有卡片。
5. 成功空结果显示淡入的空状态；请求错误仍显示错误提示。
6. 卡片和按钮在鼠标、触屏和键盘操作下都能清楚反馈；焦点指示始终可见。
7. 窄屏动效更短、位移更小；减少动态效果开启时无首屏/滚动位移动画，页面内容与功能仍完整可用。
8. 动效不遮挡主要文案、按钮或卡片信息，也不引起明显布局跳动。

## 已确认的后续范围

本规格只定义首页浏览页。本轮不定义其他页面、详情切换、管理后台或弹窗的过渡效果；后续扩展前需针对对应页面继续梳理。
